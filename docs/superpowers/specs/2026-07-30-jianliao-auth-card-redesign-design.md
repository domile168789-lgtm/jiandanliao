# 柬聊前端登录注册页品牌卡片重设计

## 背景

当前 H5 / 前端登录页与注册页已经具备基础功能，但顶部品牌区存在几个明显问题：

- 顶部品牌区过重，视觉上抢走了表单主区的注意力
- 大面积主题图和说明文案使页面显得臃肿
- `手机号` 作为第一字段不符合新的账号体系方向
- 用户前端虽然已接品牌配置，但配色气质与管理后台还不够统一

这次重设计不推翻整页结构，而是在保留现有表单能力、辅助链接和基础交互的前提下，重做顶部品牌区与字段表达。

## 用户确认结论

本次设计已确认如下方向：

- 去掉当前红框中的重型品牌展示结构
- 其他登录区功能保留，重新设计顶部
- 登录与注册统一改为 `账号`，不再使用 `手机号`
- 用户注册后，再进入用户侧由用户自行选择是否绑定手机号
- `LOGO 图片 + LOGO 名称` 重新设计，但名称主体沿用当前名称
- 用户前端的颜色参考管理后台
- 顶部采用 `品牌卡片款`
- 整体气质采用 `深浅混合`
  - 页面整体浅色
  - 品牌卡片本身为深色
- 最终方案采用 `方案 B`

## 目标

本次重设计的目标：

- 保留登录 / 注册功能不变
- 将顶部品牌区改为更轻量的小型品牌卡片
- 将 `手机号` 全部替换为 `账号`
- 将登录页和注册页的视觉系统统一
- 让前端颜色与管理后台形成同源关系

本次不做：

- 完整账号系统重构
- 手机绑定流程页面
- 登录注册接口协议改造
- 品牌名称主体更换

## 推荐方案

采用“浅色页面 + 深色品牌卡片”的混合方案。

核心思路：

- 页面整体仍然以浅色留白为主，保证表单清爽
- 顶部只保留一张小型深色品牌卡片，承担品牌识别
- 不再保留大主题图、大段文案、大欢迎语
- 登录区继续作为视觉主角

这样既能保留品牌，又不会让顶部显得压迫。

## 视觉结构

### 页面层级

从上到下分为三层：

1. 小型品牌卡片
2. 表单主区
3. 辅助操作区

新的视觉优先级应当是：

- 第一优先级：登录按钮
- 第二优先级：品牌卡片
- 第三优先级：输入框
- 第四优先级：辅助链接

### 品牌卡片

品牌卡片为新的顶部核心，但要明显小于当前版本。

结构：

- 左侧：重设计后的 logo 图片位
- 右侧：
  - 品牌名称
  - 一行极短副标，例如：`安全连接 · 即时沟通`

品牌卡片不再包含：

- 入口说明段落
- 大型主题背景图
- “欢迎回到移动端”之类的主宣传文案
- 独立品牌主题位大卡片

### 表单主区

登录页字段：

- `账号`
- `密码`

注册页字段：

- `账号`
- `密码`
- `昵称`

不在登录注册第一页中出现：

- 手机号注册
- 手机号绑定说明
- 绑定手机号流程入口

### 辅助操作区

登录页保留：

- `记住密码`
- `忘记密码`
- `注册账号`
- `全球语言切换`

注册页保留：

- `已有账号？去登录`
- `全球语言切换`

## 文案调整

### 登录页

字段与 placeholder 改为：

- `账号`
- `请输入账号`
- `密码`
- `请输入密码`

### 注册页

字段与 placeholder 改为：

- `账号`
- `请输入账号`
- `密码`
- `请设置密码`
- `昵称`
- `请输入昵称`

### 手机绑定说明

本次只在设计中约定产品方向：

- 注册完成后再由用户自行选择是否绑定手机号

本轮页面中不直接展示该流程。

## 配色规则

用户前端需参考管理后台的颜色体系，但表达方式更轻：

### 页面背景

- 浅灰白渐变
- 保持轻、干净、留白感

### 品牌卡片

- 使用深蓝黑主色
- 辅以管理后台同系蓝色做边缘高光或轻微渐变

### 主按钮

- 延续深蓝黑实色按钮
- 与后台主操作色保持一致气质

### 链接与强调文字

- 使用亮蓝色
- 保持与管理后台的蓝色强调一致

### 输入框

- 浅灰蓝边框
- 聚焦态使用蓝色描边和弱阴影

## 登录页布局

登录页从上到下建议为：

1. 小型品牌卡片
2. `账号`
3. `密码`
4. `登录`
5. `记住密码 / 忘记密码`
6. `注册账号`
7. `全球语言切换`

登录页要体现“直接登录”的目标，不再让顶部品牌区成为主视觉。

## 注册页布局

注册页沿用相同骨架，只替换表单内容：

1. 小型品牌卡片
2. `账号`
3. `密码`
4. `昵称`
5. `注册并进入`
6. `已有账号？去登录`
7. `全球语言切换`

品牌卡片应与登录页保持同一套视觉，不在注册页额外增加欢迎主题块。

## 组件边界

### `AuthPage.tsx`

需要调整：

- 删除当前大 `brand-panel + auth-hero` 双层重型结构
- 改成小型品牌卡片
- 字段从 `phone` 改为 `account`
- 标签与 placeholder 改文案

### `RegisterPage.tsx`

需要调整：

- 与登录页共用同一套品牌卡片结构
- 删除大主题块
- 注册字段从 `phone` 改为 `account`

### `styles.css`

需要重构：

- `brand-panel`
- `brand-mark`
- `auth-eyebrow`
- `auth-copy`
- `auth-hero`
- `auth-hero-copy`
- `auth-hero-label`

目标不是继续打补丁，而是把这一整组登录/注册头部样式收敛为新的“小型品牌卡片”体系。

## 交互与兼容

- 登录页和注册页仍然维持现有切换逻辑
- 品牌名称继续来自当前品牌配置
- logo 图片继续来自当前品牌配置
- 若缺少 logo 图片，则保留文字化后备占位
- 现有品牌配置中的主题图可以暂时不再用于登录/注册顶部展示

## 验收标准

完成后应满足：

- 顶部不再出现大块主题图
- 页面整体明显比当前更轻
- `手机号` 全部替换为 `账号`
- 登录和注册页风格统一
- 页面颜色与管理后台明显同源
- 品牌卡片仍保留 logo 图片与名称展示
- 登录按钮仍然是页面最强视觉焦点

## 风险与边界

### 风险

- 如果直接删除现有头部结构但没有重建层级，页面可能过于空
- 如果品牌卡片做得过大，容易再次回到当前“上重下轻”的问题

### 边界

- 本次只做 UI / 文案 / 信息层级重设计
- 不涉及后端接口协议
- 不涉及手机号绑定功能实现
