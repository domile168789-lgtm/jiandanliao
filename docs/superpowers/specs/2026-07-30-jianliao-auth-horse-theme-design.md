# 柬聊登录页马年主题重设计

## 背景

当前登录页已经完成过一轮“账号体系 + 品牌卡片”重构，但用户希望进一步参考春节海报型视觉，采用更明确的马年主题背景来重做登录页气质。

这次不是继续沿用浅色卡片式登录页，而是改为：

- 全屏马年主题背景
- 顶部居中的柬聊品牌
- 中部极简登录表单
- 底部辅助操作

本轮目标是把登录页做成“海报氛围 + 功能前景”的结构，而不是把整张海报原样搬进页面。

## 用户已确认方向

用户已明确确认以下要求：

- 主题背景参考红金白马的新春主题图
- 删除图片中的 `VIP`
- 背景图需要增加透明度 / 压淡
- 背景只做氛围层，不抢登录功能
- 顶部品牌区：
  - 保留 `柬聊 Logo / 名称`
  - 放在上方居中
  - 不再堆额外说明文案
- 中部登录区只保留：
  - `账号`
  - `密码`
  - `登录按钮`
- 底部辅助区只保留：
  - `记住密码`
  - `注册账号`
  - `语言切换`
- 用户已认可，要求直接实施

## 目标

本次重设计的目标：

- 登录页视觉改成马年新春主题
- 保留最少量、最明确的登录元素
- 让背景图存在但退后
- 让 Logo、输入框、按钮成为前景焦点

本次不做：

- 注册页新春海报化重做
- 账号系统协议改造
- 手机绑定流程实现
- 聊天页、活动页、首页其他模块联动改造

## 页面结构

从上到下固定为三层：

### 1. 顶部品牌区

内容只保留：

- `柬聊 Logo`
- `柬聊 名称`

布局要求：

- 上方居中
- 不放副标题说明段落
- 不放欢迎语
- 不放品牌副卡片

### 2. 中部登录区

只保留以下内容：

- `账号`
- `密码`
- `登录按钮`

要求：

- 输入框清晰、统一、易读
- 按钮是页面最强操作焦点
- 不在这里放额外说明文字

### 3. 底部辅助区

只保留：

- `记住密码`
- `注册账号`
- `语言切换`

要求：

- 视觉弱于登录按钮
- 不加入“忘记密码”等额外项，避免打乱用户已确认结构

## 背景图策略

### 背景图来源

背景图参考用户提供的红金白马海报型主题图，保留这些视觉元素：

- 红橙主色背景
- 白马主视觉
- 金色丝带 / 祥云 / 山体 / 纹样
- 新春氛围

### 必须处理

- 删除图片中的 `VIP`
- 删除原始海报中的非柬聊品牌文案
- 不直接使用整张海报的现成排版

### 使用方式

背景图作为全屏背景铺开，但必须做弱化处理：

- 增加透明度
- 加一层柔化遮罩
- 适当暗化或雾化
- 保证输入框、按钮、Logo 可读

结论：

- 背景图是“氛围层”
- 登录表单是“前景层”

## 视觉风格

### 主基调

- 新春海报风
- 红金暖色调
- 中国风节庆感
- 极简功能布局

### 视觉层级

优先级从高到低：

1. 登录按钮
2. 账号 / 密码输入框
3. 柬聊 Logo / 名称
4. 主题背景图
5. 底部辅助操作

### Logo / 名称

建议：

- 用偏暖白或浅金白
- 居中显示
- 尺寸适中，不像海报标题那样过大
- 作为品牌识别而非主宣传文案

### 输入框

建议：

- 半透明浅色输入框
- 细边框
- 中高圆角
- 聚焦时使用暖金或浅白金描边

### 登录按钮

建议：

- 金色或暖金色胶囊按钮
- 比输入框更有重量
- 保持干净，不加入复杂装饰

### 辅助操作

建议：

- 使用浅暖白或浅金灰
- 透明度低于按钮
- 不抢中心操作

## 信息裁剪原则

为了保证登录页可用性，本轮必须避免以下问题：

- 把整张春节海报原样铺上去
- 背景图过亮，压住输入框
- Logo 太大，和白马主视觉冲突
- 文案过多，重新变成海报阅读页

页面必须只表达一件事：

- “在马年主题氛围下完成登录”

## 组件边界

### `AuthPage.tsx`

本次重点修改文件。

需要改动：

- 登录页结构重排
- 去掉当前表单头部说明文案
- 调整为顶部品牌、中部登录、底部辅助三段式
- 保留 `账号 / 密码 / 登录按钮 / 记住密码 / 注册账号 / 语言切换`

### `styles.css`

需要改动：

- 登录页背景图样式
- 遮罩层
- 顶部品牌区样式
- 输入框和按钮样式
- 辅助区位置与颜色

### `RegisterPage.tsx`

本轮不作为主要改动目标。

如果为了保持最小一致性需要微调样式，可做轻量同步，但不要求把注册页完整改成同一张马年海报结构。

## 验收标准

完成后必须满足：

- 页面能明显看出马年新春主题
- 背景图已压淡，不会喧宾夺主
- `VIP` 不再出现
- 顶部只保留柬聊 Logo / 名称
- 中部只有账号、密码、登录按钮
- 底部只有记住密码、注册账号、语言切换
- 登录页整体比原海报更克制、更像产品界面

## 风险与约束

### 风险

- 如果背景压淡不够，输入框和按钮会难读
- 如果背景压得太狠，又会失去用户想要的年味
- 如果 Logo 做太大，会和白马主体争视觉中心

### 约束

- 不改后端接口
- 不改登录跳转逻辑
- 不在这一轮扩展到更多页面
